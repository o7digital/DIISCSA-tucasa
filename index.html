BASE VERIFICADA

Módulos identificados en el código de PulseCRM de O7. La adaptación a DIICSA, las credenciales y las pruebas de extremo a extremo forman parte de la implementación.

Ver alcance técnico

Repositorio: o7digital/crm-suites-o7. Base Next.js, NestJS, Prisma y PostgreSQL. Se propone reutilizar módulos seleccionados; esta demostración no está conectada a la API del CRM.

Newsletter: audiencias de clientes, personalización, prueba y envío. Social: canales y programación mediante Buffer. Usuarios, clientes, tareas y seguimiento postventa disponibles como base. Academia, hogares, solicitudes, evidencias y experiencia móvil requieren adaptación o desarrollo.
